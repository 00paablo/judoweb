# Visual system

## Direction

Kodokan registry and scorekeeper: a professional editorial system for learning Judo and running a dojo competition. The interface uses warm paper surfaces for reference content and a deep ink-navy scorekeeper surface for live matches.

## Palette

- Paper: `#f3f1ec`
- Surface: `#ffffff`
- Ink: `#172235`
- Muted ink: `#586576`
- Vermilion action: `#a8252d`
- Brass detail: `#9a7623`
- Scorekeeper navy: `#142238`

## Typography

- UI and navigation: IBM Plex Sans
- Editorial headings and Japanese display: Noto Serif JP
- Data readouts: existing monospace treatment for time and measurements

## Composition

Use generous paper margins, restrained borders, compact square controls, and clear section rules. Belt progression uses an obi-inspired control rail and a dark, readable current-rank panel; Tokui-Waza is an integrated exploration module inside Techniques, not a separate app-like page. Cards are flat white working surfaces with subtle neutral elevation; avoid glass, neon glows, and ornamental gradients. The tournament desk is intentionally darker to separate live operational work from reference content.

## Interaction

Actions use high-contrast vermilion, secondary controls use pale surfaces with a defined border, selected states use vermilion or brass, and focus states use a visible outline. The live scorekeeper is a structured dark referee console with a dedicated state rail and high-contrast scoring cells. Match start uses the existing dojo gong cue; tournament state labels are explicit and the Professor Kano assistant stays available through a compact deployable left launcher across pages. Motion is short and state-driven.

## Responsive behavior

Desktop navigation and two-column editorial layouts collapse into stacked reading and operating flows below 1024px. Tournament brackets remain horizontally scrollable instead of shrinking names into unreadable cells.
